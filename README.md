# AssureCompare

Home insurance comparison website: find the right policy in a few clicks.

## Features

- Insurance offer comparison
- FAQ, contact and legal pages
- Responsive UI

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/assure-compare.git
cd assure-compare
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
